### Case Study Template
**Use for:** Project success stories, client impact, deliverables  
**Sections:** Overview, Metrics, Delivery, Team, Impact, Executive Summary  
**Length:** 2-4 pages  
**Best for:** Customer-facing reports

```

Edit sections:
  - [Project Title]
  - [Business Problem]
  - [Key Metrics]
  - [Team Members]
```

**Use for:** Post-meeting analysis, feedback, lessons learned

## 💡 Pro Tips

✅ **Save your color choice** - It persists across browser sessions  
✅ **Use client brand colors** - Pick MUFG Red or custom color  
✅ **Test print first** - Use "🖨️ Print / PDF" button  
✅ **Keep metrics simple** - 3-6 key numbers only  
✅ **Make executive summary punchy** - 2-3 sentences max

## 🔧 Editing Content

### Where to Edit
1. **Browser Preview:** Click "✏️ Edit Mode" for instructions
2. **Text Editor:** Download HTML, open in VS Code or Notepad
3. **Developer Tools:** Right-click → Inspect, edit directly

### What to Replace
```html
[Project Title]           → "MUFG Agentic Share Sale"
[Client Name]            → "MUFG"
[Business Problem]       → Describe the challenge
[Team Member Name]       → "Nishant Patnaik"
[image-url]              → "images/photo.jpg"
[pega-logo-url]          → "images/pega-logo.png"
[client-logo-url]        → "images/client-logo.png"
[...]                    → Your actual content
```

## 🖨️ Export to PDF

1. Click **"🖨️ Print / PDF"** button
2. Choose **"Save as PDF"**
3. Name it: `ClientName_Project_Date.pdf`
4. Share with stakeholders

**Result:** Professional PDF ready for client delivery

## ❓ Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Color not showing | Reload page, clear browser cache |
| Images not visible | Check path format: `images/photo.jpg` |
| Template won't load | Ensure HTML file is in correct folder |
| Print looks broken | Use "🖨️ Print / PDF" button, not Ctrl+P |
| Can't edit | Download HTML and edit in text editor |
