## ✨ Easy Editing - 3 Ways

### **Method 1: Click "Edit Mode" Button** ⭐ EASIEST

This is the recommended way to edit templates in your browser!

**Steps:**
1. Open template (Case Study or Debriefing)
2. Click **"✏️ Edit Mode"** button at top
3. All editable text highlights in **yellow**
4. **Click any yellow text** to edit it directly
5. Type your changes
6. Click **"✓ Done Editing"** when finished
7. Click **"🖨️ Print / PDF"** to save

**What's editable:**
- ✅ Project title and subtitle
- ✅ Business problem, scope, solution
- ✅ Team member names and roles
- ✅ Client impact sections
- ✅ Metadata (client name, date, etc.)
- ✅ Executive summary
- ✅ All [bracketed placeholder text]

---

### **Method 2: Download and Edit in Text Editor**

For more complex edits, download the HTML and edit in Notepad/VS Code:

**Steps:**
1. Right-click template page → **Save as**
2. Choose **"Web Page, HTML only"** format
3. Open file in text editor (Notepad, VS Code, etc.)
4. Find [bracketed text] to replace
5. Edit content
6. Save file
7. Open in browser to preview

**Example:**
```html
<!-- Find this: -->
<h1>[Project Title]</h1>

<!-- Replace with: -->
<h1>MUFG Agentic Share Sale Experience</h1>
```

---

### **Method 3: Copy/Paste Content**

If you have content in a document:

**Steps:**
1. Click "✏️ Edit Mode"
2. Yellow text appears
3. Click on a section (e.g., Business Problem)
4. **Ctrl+A** to select all text in that section
5. **Ctrl+V** to paste your content
6. Repeat for other sections
7. Click "✓ Done Editing"

## 💡 Pro Tips

### ✅ **DO:**
- ✅ Use clear, concise language
- ✅ Include specific numbers and metrics
- ✅ Edit one section at a time
- ✅ Review before printing to PDF
- ✅ Print to PDF immediately after editing (data may not persist after page refresh)

### ❌ **DON'T:**
- ❌ Refresh the page without saving (edits will be lost)
- ❌ Close browser without printing to PDF
- ❌ Try to edit non-highlighted text (won't work)
- ❌ Use very long paragraphs (keep it concise)
- ❌ Edit while in Print Preview mode

## ⚡ Quick Reference

### **Keyboard Shortcuts**
| Action | Shortcut |
|--------|----------|
| Enter edit mode | Click "✏️ Edit Mode" button |
| Select all text in section | Ctrl+A (or Cmd+A on Mac) |
| Paste content | Ctrl+V (or Cmd+V on Mac) |
| Undo last change | Ctrl+Z (or Cmd+Z on Mac) |
| Redo change | Ctrl+Y (or Cmd+Y on Mac) |
| Bold text | Ctrl+B (or Cmd+B on Mac) |
| Print to PDF | Ctrl+P (or Cmd+P on Mac) |

## ❓ Troubleshooting

| Problem | Solution |
|---------|----------|
| Can't click to edit | Make sure "✏️ Edit Mode" is activated (button should say "✓ Done Editing") |
| Yellow highlights not showing | Refresh page and try again |
| Text disappeared after editing | Refresh and start over (edits in browser don't persist) |
| Can't find [bracketed text] | Use Ctrl+F to search for "[" or "]" |
| Want to keep edits | Print to PDF immediately - that saves them |
| PDF looks different than browser | This is normal; PDFs render slightly differently |

## 📞 Quick Help

**Question:** How do I save my edits?
**Answer:** Click "🖨️ Print / PDF" → Save as PDF. That's the only way to preserve your edits.

**Question:** Can I edit without Print Mode?
**Answer:** No, use the "✏️ Edit Mode" button to enable editing.

**Question:** What if I make a mistake?
**Answer:** Use Ctrl+Z to undo, or refresh the page and start over.

**Question:** Can others edit my PDF?
**Answer:** No, PDF is read-only. They would need the HTML template to edit.
